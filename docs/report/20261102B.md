1. **Unsafe Intrinsic Block Synthesis**:

     1. Importing `std::arch::x86_64::*`.
     2. Enclosing calls in `unsafe { ... }` blocks.
     3. Attaching target feature annotations: `#[target_feature(enable = "avx2,fma")]`.
   - While Claude 3.5 Sonnet has internalized Rust's `unsafe` ergonomics, the local 27B model (`swift-1.5-qwen3.8-27b`) frequently emitted raw intrinsic function calls directly inside safe functions, triggering `E0133` ("call to unsafe function requires unsafe function or block").
2. **Type Coercion Invariants**:
   - The C implementation freely casts multidimensional pointer indices (`int x, int y`) into memory offsets.
   - The local SLM struggled to balance `usize` indexing with `Vec<Vec<f32>>` while simultaneously attempting pointer casts (`E0605`).
